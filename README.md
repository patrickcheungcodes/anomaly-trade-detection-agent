# Fund Operations - Agentic Trade Anomaly Detection & Risk Reporting Tool

## Problem Statement
Daily trade and position monitoring in fund operations is often manual and time-consuming. This tool helps operations by automatically detecting anomalies in trade/position data and generating clear, explainable risk reports using agentic AI.

## Objective
Build a practical agentic Python tool that:
- Processes trade and position data using pandas
- Flags potential anomalies using statistical methods
- Uses Google Gemini API as an agentic AI to provide professional natural-language explanations and risk insights
- Produces easy-to-read reports for ops and risk review

## Key Features (Planned)
- Data loading and cleaning with pandas
- Statistical anomaly detection (Z-score and threshold-based)
- Agentic reasoning with Gemini for explainable outputs
- Structured risk reporting
- Interactive dashboard with Streamlit (Phase 2)

## Tech Stack
- Python
- pandas, numpy
- Google Gemini API (gemini-2.5-flash)
- Streamlit
- Power BI (for visualization)
